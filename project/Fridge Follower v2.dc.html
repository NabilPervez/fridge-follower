Fridge Follower

This version has jewel-tinted glass surfaces, Phosphor duotone icons, Geist for UI text, and a floating tab bar. Earlier version: v1.

New in v2 Fridge: use − and + on any row to lower or raise a level. Tap the row to set an exact level, change location, toggle staple, or delete it. Swipe still works. Recipes: tap + to write a recipe by hand, paste recipe text, or import a .json or .txt file. Imported recipes open in the editor for review. Ingredients are matched to your inventory, and new ones are created as Out. Recipe detail: the pencil opens the editor.
